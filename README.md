# Brain Signaling & Neurolipids Lab

Website of the Brain Signaling & Neurolipids Lab (IQAC-CSIC, Barcelona), served with GitHub Pages at https://brainliplab.github.io

- `index.html` — the whole site (HTML, CSS and JS in one file)
- `photos/` — member pictures (square, ~360 px)
- `logos/` — funding logos
- `video/` — simulation movies (MP4, H.264) and their poster frames

To update: edit `index.html`, commit and push; changes go live in a minute or two.
